# =========================================================
#  双AI对话实验室 · 场景预设合集（剧本杀 / 对立博弈 / 脑洞）
# =========================================================
# 用法：
# 1) 每个预设只复制 persona = ... 、topic = ... 、rounds = ... 这几行，
#    覆盖 config.txt 里对应的行（base / key / name 等保留你自己的）。
# 2) 保存后到网页「对话设置」点「⟳ 从 config.txt 重载」。
# 3) ⚠️ 先「清空聊天记录」再开跑——冷启动才会注入场景设定开场。
# 4) 剧本杀本子里，【你】= 主持人：用输入框插话抛线索、报时间、
#    下判决（插话会以【人类插话】出现在两位 AI 面前）。
# 5) 值里的 \n 是换行，别删。
# =========================================================

# ◆ 主持人台词卡 ｜《午夜特快》专用 ◆
# 操作：底部输入框打字 → 回车即插话。
# 跑法：轮数填 -1，点「▶ 继续」无限自动聊，你随时插话加戏；
#      「人类插话后先回应」选 A（让沈探长先接你的线索）。
# 心法：一次只抛一条线索，等他们消化 1~2 轮再抛下一条；
#      先中性、再指向真凶、最后铁证，戏才够长。
############################################################
# 【开场后等2~3轮】列车广播：暴风雪加剧，全线信号中断，预计一小时后修复。
# 【线索1·中性】法医报告：死者胃里检出氰化物，毒是随咖啡服下的。杯壁只有死者本人指纹——毒不是下在杯子里的。
# 【线索2·指向七号】乘务员证词：午夜前后，一位衣着整齐的乘客从餐车快步走向三号车厢，手里似乎拿着一本书。
# 【施压】广播：备用信号已恢复，前方站台警方待命，列车一停将立即登车搜查。
# 【铁证·最后一击】三号车厢书架搜出一只空毒瓶，夹在《东方快车谋杀案》第137页。
# 【逼终局】广播：列车即将修复。沈探长，请现在给出你的最终指认。
# 【若探长指认错了】广播：警方核查——该乘客有确凿不在场证明。探长请重新指认。
# 【复盘收尾】请两位摘下角色，互相点评：刚才谁的演技更好？破绽在哪里？
