勾选 = 参与本轮，按勾选顺序发言（气泡上 ▲▼ 可调序）；留空 = 全部按配置顺序参与。

📖 使用说明 快速开始：① 用 Chrome/Edge 打开本页，点右上「连接目录」，选择本 html 所在文件夹（授权后即可直接读写各 txt）；② 展开配置，为每个 AI 填写 API 地址 / Key / 模型 / 人设（可「➕ 添加 AI」扩展数量）；③ 填写「场景设定」，点中间「▶ 开始聊天」。
数据文件（与 index.html 同目录）：memory_aiN.txt = 每个 AI 一个记忆文件；chat_log.txt = 聊天记录（所有 AI 共用，程序按 ### [ID] 时间 分段解析后作为上下文发给模型）；config.txt = 全部配置（[AI1] [AI2]… 分节 + [全局]），页面改动自动写回，手动编辑后点「⟳ 重载配置」生效。
发言顺序与参与：「发言顺序」多选下拉：勾选的 AI 参与本轮，按勾选顺序发言（气泡 ▲▼ 可调序），留空＝全部按配置顺序参与；「开场先发言」＝新对话第一句谁说；「人类插话后先回应」＝插话后从谁开始；未填 Key 的 AI 自动跳过。轮数按「轮」计，1 轮 = 参与的每个 AI 各发言一次；轮数填 -1 = 无限轮数，对话一直进行，点「⏸ 暂停」结束。
记忆机制：开启「自动记忆」时，每个 AI 每次发言后会在后台把「当前记忆 + 完整聊天记录」交给自己的模型整理出新记忆并写回自己的记忆 txt；也可手动编辑后点「保存修改」，或点「AI整理」立即更新。
思考过程：开「思考」开关后，气泡内可展开查看该 AI 的推理内容（仅展示，不写入 txt）。
人类插话：「发送」= 写入聊天记录，参与 AI 依次各回复一条（1 轮）后停下等你；「▶ 继续」= 让 AI 们自行接着聊（不再等人类）；AI 对话进行中随时发消息可即时插入。
打不开本地文件？该能力仅 Chrome/Edge 支持（file:// 直接双击一般可用）；若受限，在本目录运行 node server.js 后从 localhost 访问即可。其他浏览器会自动降级为浏览器内暂存 + 手动导入导出。
